AICTE Security Deposit & FDR Management Portal

Hackathon prototype: a centralized portal for the AICTE Regulation Bureau to manage institution-wise security deposits and FDRs.

What it does

  • Central repository of deposits and FDRs with document versions
  • Verification against bank data and automatic discrepancy detection
  • Maturity tracking with 90/60/30/15/7-day reminders
  • Renewal chain (parent to child instruments)
  • Multi-stage release workflow: Institution, Scrutiny Officer, Approving Authority
  • Role-based access, append-only audit trail, AES-256-GCM encryption
  • Dashboard with charts and CSV export (impact metrics are simulated)
